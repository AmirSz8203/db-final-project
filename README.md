# 🛒 DB Final Project — Amazon Clone

A full-stack clone of the Amazon shopping experience, built as a final project for a database course. It pairs a vanilla HTML/CSS/JS frontend with a FastAPI + SQLite backend, covering product browsing, cart management, checkout, order tracking, and JWT-based authentication.

## ✨ Features

- 🔍 Browse and search products with ratings, discounts, and keywords
- 🛍️ Add items to cart and proceed through checkout with delivery options
- 🔐 User signup/login secured with JWT tokens and bcrypt-hashed passwords
- 📦 Order history and shipment tracking
- 🗄️ Relational SQLite schema for products, ratings, keywords, users, and orders

## 🧱 Tech Stack

**Frontend**
- HTML5 / CSS3 / vanilla JavaScript (ES Modules)
- Google Fonts (Roboto)

**Backend**
- [FastAPI](https://fastapi.tiangolo.com/)
- SQLite (via Python's `sqlite3`)
- `python-jose` for JWT auth
- `passlib[bcrypt]` for password hashing
- `uvicorn` as the ASGI server

## 🗄️ Database Schema

- **products** — id, name, image_path, price_cents, discount_pct
- **ratings** — product_id, stars, count
- **keywords** / **product_keyword_map** — many-to-many product tagging
- **users** — id, username, email, password_hash
- **orders** / **order_items** — user orders and their line items

## 🚀 Getting Started

### 1. Backend setup

```bash
cd backend
python -m venv venv
source venv/bin/activate      # on Windows: venv\Scripts\activate
pip install -r requirements.txt

# Seed the database from products.json
python load_data.py

# Start the API server
uvicorn api:app --reload --port 8000
```

The API will be available at `http://localhost:8000`, and product images are served at `http://localhost:8000/images/...`.

### 2. Frontend setup

The frontend is static HTML/CSS/JS, so no build step is needed. Just serve the root folder with any local server (e.g. VS Code's **Live Server** extension) — the backend's CORS config expects `http://localhost:5501` or `http://127.0.0.1:5501`.

Then open `amazon.html` in the browser.

## 🔌 Key API Endpoints

| Method | Endpoint          | Description                     |
| ------ | ----------------- | -------------------------------- |
| POST   | `/signup`          | Register a new user              |
| POST   | `/token`           | Log in and receive a JWT         |
| GET    | `/users/me/`        | Get the current authenticated user |
| GET    | `/products`         | List products (paginated)        |
| GET    | `/products/{id}`    | Get a single product             |
| POST   | `/orders`           | Create an order (auth required)  |
| GET    | `/orders`           | Get the current user's orders    |

## ⚠️ Notes

- This is an educational project — the JWT secret key in `api.py` is hardcoded and should **not** be used as-is in production; load it from an environment variable instead.
- `myshop.db` is regenerated by `load_data.py`, so any manual DB edits will be lost on re-seed.
